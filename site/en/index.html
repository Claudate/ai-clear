Reclaim the space AI coding tools and builds leave behind

Cleanling is a macOS cleanup tool for the caches that Cursor, Claude Code, Codex and VS Code scatter around, plus Rust target directories, node_modules and package manager caches — things that rebuild themselves but keep growing.

Three rules it does not break

It will not mess with your files

The whole design follows one principle: space is reclaimed, not gambled.

1

Scanning only reads

A scan reads file metadata only. It writes nothing, moves nothing and deletes nothing. It just answers: which space is safely reclaimable?

2

Quarantine by default

Once you confirm, items move to a quarantine area and can be put back for 7 days. Releasing space immediately requires explicitly choosing Direct Delete, which asks for another confirmation.

3

Protected things cannot get in

Keys, configuration and session history are blocked by hard-coded guards built into the binary, so even a broken rule file cannot get past them.

Every item says what deleting costs

Not colored dots, a sentence

Specific enough to decide on.

Reclaimable

Rebuilds automatically

Pure cache files. Deleting them has no impact on use; they regenerate on the next run.

Costly

Space freed, but recompile/redownload

Build artifacts and dependency caches — usually the biggest items, with a real cost for the next build or download. Costly items are unchecked by default; the decision is yours.

Protected

Never moved

Your records, keys and configuration. The tool will not touch them or list them as cleanup candidates.

Optional AI analysis

Local verdicts first; AI is just an assistant

Scanning and verdicts happen entirely on your Mac. Only when you configure a model provider in Settings and click AI analysis does Cleanling send a summary of the current scan to that provider.

·

No upload by default

With no provider configured, the app makes no network requests at all. Paths, sizes and verdicts are handled locally.

·

Summary only, not file contents

What is sent is scan metadata (relative paths, types, sizes, verdicts) with a hard cap. File contents are not sent by default, and content sampling includes a secret-fingerprint check.

·

AI never executes on its own

AI proposals are verified item by item before anything runs, and still follow the three rules above.

The interface

Clear at a glance

Occupancy ranking, the reclaimable list, quarantine and history — all readable on one screen.
