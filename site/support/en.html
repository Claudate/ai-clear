FAQ

Why does Cleanling need Full Disk Access? What happens without it?

Cleanling reads caches under ~/Library/Caches and tool directories under ~/ (such as ~/.claude, ~/.codex, ~/.cargo). macOS protects these paths; they are only visible after you grant Full Disk Access in System Settings → Privacy & Security.

Without the permission, Cleanling still runs but only sees a limited set of paths, and the interface tells you which folders could not be read. Scanning is always read-only and never modifies files because of this permission.

Does scanning upload my files?

No. Scanning and verdicts happen entirely on your Mac. Paths, sizes and verdicts never leave the device. Cleanling has no accounts, no analytics and no crash reporting.

The only network behavior is AI analysis, which is off by default — it sends a summary of the current scan to a provider only when you configure one in Settings and actively click AI analysis. See the Privacy Policy.

What is quarantine, and how long are items kept?

Quarantine is where moved files are kept. After you confirm cleanup, items go to quarantine and are kept for a default of 7 days, restorable to their original location at any time.

Direct Delete removes items from their original location without quarantine and asks for a second confirmation. Note that moving to quarantine does not immediately free disk space — space is freed when quarantine contents are purged or expire after 7 days.

What does AI analysis send, and to whom?

AI analysis is optional: with no provider configured, the app makes no network requests. Once configured, Cleanling sends a summary of the current scan only to the address you configured (e.g. DeepSeek, OpenAI, Anthropic, or a local Ollama instance) — metadata such as relative paths, item types, sizes and verdicts, capped at 120 items.

File contents are not sent by default. Content sampling reads only the first few bytes of small text files and runs a secret-fingerprint check first; on a match the whole sample is dropped. API keys are used only to call the provider you selected.

Why are build artifacts unchecked by default?

Build artifacts (like target) are usually the largest items, but deleting them means the next build has to recompile or redownload — a real time cost. They are classed as “costly” and unchecked by default, so the decision stays yours.

What does “Find duplicate files” do? Does it delete anything?

“Find duplicate files” finds files with identical content. It only reads files for comparison — it does not delete or move anything. Results list each duplicate group and how much you save by keeping one copy, and you decide which copy to keep.

If a scan is truncated by its time budget, the app clearly says “not finished”, so a partial scan is never reported as having no duplicates.

Which macOS versions and architectures are supported?

macOS 13.0 (Ventura) or later. The current build targets Apple Silicon (arm64).
