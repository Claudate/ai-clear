# App 隐私问卷答案（App Store Connect → App 隐私）

按 2026-10 的 App Store Connect 问卷逐题给出该选什么，以及为什么。填错这里
是审核被打回最常见的原因之一，所以每一项都对着代码的实际行为写，不凭印象。

## 一、总体

**「此 App 是否收集数据？」→ 是**

不能答「否」。虽然扫描结果不上传，但只要存在「把数据发到你自己配置的第三方
模型服务」这条路径，Apple 就要求申报。答否而实际有网络发送，属于 5.1.1 的
隐私披露不实。

## 二、申报哪些数据类型

只申报下面这一类，其余全部不勾。

| 数据类型 | 是否勾选 | 说明 |
|---|---|---|
| 用户内容 → 其他用户内容 | **勾选** | 扫描摘要中的文件路径与体积 |
| 标识符 | 不勾 | 无账号、无设备 ID、无 IDFA |
| 使用数据 | 不勾 | 无埋点、无统计 SDK |
| 诊断 | 不勾 | 无崩溃上报 |
| 位置 | 不勾 | 不申请定位权限 |
| 联系信息 | 不勾 | 没有登录，不收邮箱姓名 |
| 财务信息 | 不勾 | —— |
| 健康与健身 | 不勾 | —— |
| 浏览历史 | 不勾 | —— |
| 搜索历史 | 不勾 | 搜索框只过滤本地清单，不发请求 |
| 联系人 | 不勾 | —— |
| 敏感信息 | 不勾 | 密钥在发出前就被指纹拦掉 |

## 三、每一类数据的用途与关联

对「其他用户内容」逐项回答：

- **用途：App 功能**（App Functionality）。这是唯一正确的选项——摘要只用于
  生成分析结果给用户自己看。
- **是否用于追踪（Tracking）：否。** 不与第三方广告数据关联，不做跨 App 画像。
  这一项必须答否，否则会强制触发 ATT 弹窗，而本 App 没有任何追踪行为。
- **是否与用户身份关联（Linked to the user）：否。** 没有账号系统，请求里
  不带任何用户标识。
- **是否用于广告或营销：否。**

## 四、隐私政策 URL

必填，且必须能公开访问（不能是登录墙后的页面）。仓库里的
`store/privacy-policy.zh-Hans.md` / `.en-US.md` 需要发布到网站上再填链接。
App Store Connect 会实际抓取这个地址，抓不到就提交不了。

## 五、审核备注里必须主动交代的三件事

Apple 审核员不会去猜一个清理工具为什么要读 `~/Library`。以下三点写进
「审核备注」（内容见 `store/review-notes.md`）：

1. 为什么需要「完全磁盘访问权限」，不授权时哪些功能仍在工作；
2. AI 分析是可选的，不配置时不联网，以及数据发给谁；
3. 本 App 有删除文件的能力，但默认只移入隔离区、7 天可还原——这条直接回应
   Guideline 2.4.5 对「修改其他 App 数据」的关注。
